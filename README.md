# Ti — студия бровей

Адаптивный сайт и Telegram Mini App для запросов на запись и отзывов. Интерфейс сохраняет спокойную editorial-стилистику Ti; портфолио и реальные контакты не подменяются выдуманными данными.

Сейчас услуги и цены на странице — **тестовые**. Запрос на время сохраняется, но становится записью только после личного подтверждения мастером. Записи и отзывы автоматически удаляются из KV через 180 дней.

## Что работает

- Пошаговая заявка: услуга → дата и время → имя и способ связи.
- Заявка сохраняется в Cloudflare KV; уведомление отправляется в Telegram, если бот настроен.
- Если API недоступен или не подключён, сайт явно сообщает, что запрос не отправлен.
- Отзывы сохраняются как ожидающие проверки; на сайте показываются только одобренные.
- Кабинет мастера: список заявок, публикация и отклонение отзывов.
- Статические файлы публикуются GitHub Pages из `main`; при использовании этой Pages-ссылки как URL Mini App в Telegram обновление сайта появляется в боте автоматически.

## Cloudflare Worker

1. В Cloudflare создай Worker `ti-studio-api` и опубликуй содержимое `brow-worker.js` как module worker.
2. Создай KV namespace, например `ti-studio-kv`, и подключи binding с именем **`BK`**.
3. В Settings → Variables and Secrets задай:
   - `ADMIN_KEY` — **secret**, случайное значение не короче 32 символов.
   - `BOT_TOKEN` — **secret** токена Telegram-бота.
   - `CHAT_ID` — id чата, куда отправлять заявки и новые отзывы.
   - `ALLOWED_ORIGINS` — `https://xstayis-hue.github.io` (и origin локального сервера разработки, если нужен).
4. Задеплой Worker и открой его `/api/health`. Для состояния `ready: true` нужны KV и `ADMIN_KEY`.
5. Скопируй URL Worker в `API_BASE` внизу `index.html`, убрав завершающий `/`, и отправь изменение в `main`.

**Не добавляй токен бота или ключ кабинета в HTML, репозиторий, URL или чат.** Секреты должны существовать только в Cloudflare. Если сайт использует новый адрес, добавь его в `ALLOWED_ORIGINS`.

В кабинете нажми «Вход мастера» и введи тот же `ADMIN_KEY`. Ключ хранится только в `sessionStorage` текущей вкладки и передаётся API заголовком `Authorization`, не query-параметром.

## GitHub Pages и Telegram

- URL сайта: <https://xstayis-hue.github.io/BrowwwTi/>
- Репозиторий настроен на публикацию `main` в GitHub Pages.
- Если в настройке Mini App бота уже указан этот URL, менять его не нужно. После успешного Pages deploy закрой Mini App в Telegram полностью и открой снова.
- Worker публикуется отдельно от сайта; один только push в GitHub не разворачивает backend.

## Тестовый каталог

Список услуг и цен находится в двух местах и должен совпадать:

- `index.html` — массив `SERVICES`.
- `brow-worker.js` — объект `SERVICES`.

При замене тестового прайса сохраняй `id` каждой услуги одинаковым в обоих файлах. Фотографии работ и ссылки на контакты добавляй только после получения реальных материалов.
